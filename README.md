# Генератор договоров · Комплекс-27

Веб-приложение для автоматического заполнения типовых договоров данными клиента.
Оператор загружает карточку партнёра, программа извлекает реквизиты, правильно
**склоняет ФИО подписанта** и формирует готовый договор в форматах **.docx** и **PDF**.

Работает целиком в браузере — **данные клиентов никуда не отправляются**, всё
обрабатывается на компьютере оператора. Серверная часть не нужна.

---

## Что умеет

- **3 типа договоров**: ТЭО, смешанный, договор поручения (таможенное оформление).
  Ваши реквизиты (ООО «Комплекс-27») уже вшиты в шаблоны, заполняются только поля клиента.
- **Автоматический разбор карточки** (.docx, .txt, .pdf) — извлекает наименование,
  ИНН/КПП, ОГРН, адреса, счета, БИК, банк, ФИО и должность подписанта.
  Работает с разными форматами карточек (таблицы и сплошной текст).
- **Склонение ФИО** в родительный падеж («в лице директора Иванова Ивана Ивановича»)
  и формирование подписи («Иванов И.И.»). Пол определяется по отчеству автоматически.
- **Гибридный режим**: оператор проверяет и правит автозаполненные поля перед созданием.
- **Экспорт** в .docx (с сохранением форматирования) и PDF.

## Как развернуть на GitHub Pages

1. Создайте репозиторий на GitHub (например, `contract-generator`).
2. Загрузите в него всё содержимое этой папки (кнопка **Add file → Upload files**,
   либо через `git`):

   ```bash
   git init
   git add .
   git commit -m "Генератор договоров"
   git branch -M main
   git remote add origin https://github.com/ВАШ_АККАУНТ/contract-generator.git
   git push -u origin main
   ```

3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)** → **Save**.
5. Через 1–2 минуты страница будет доступна по адресу
   `https://ВАШ_АККАУНТ.github.io/contract-generator/`.
   Эту ссылку давайте операторам.

> **Приватность ссылки.** GitHub Pages делает страницу общедоступной по ссылке,
> даже если репозиторий приватный (виден будет только сайт, не код). Если ссылка
> не должна быть публичной — разверните на внутреннем сервере компании
> (см. ниже), файлы те же.

### Альтернатива: внутренний сервер / локально

Приложение — это статические файлы. Достаточно отдать папку любым веб-сервером:

```bash
# Python (для проверки локально)
cd contract-generator
python3 -m http.server 8080
# откройте http://localhost:8080
```

Или скопируйте папку в каталог nginx/Apache/IIS вашей компании.

> Открывать `index.html` двойным кликом (протокол `file://`) **не сработает** —
> браузер заблокирует загрузку шаблонов. Нужен веб-сервер (даже локальный, как выше).

## Как пользоваться

1. Выберите **тип договора** (ТЭО / смешанный / поручение).
2. **Заполните поля клиента.** Два пути:
   - **Вручную** — все поля доступны для ввода сразу.
   - **Из карточки** — загрузите файл карточки (.docx/.txt/.pdf), поля заполнятся
     автоматически; взятые из карточки подсвечиваются зелёным.
3. Укажите **номер и дату** договора, проверьте **полное и краткое наименование**
   (два отдельных поля, например «Общество с ограниченной ответственностью
   «Комплекс-27»» и «ООО «Комплекс-27»»).
4. Проверьте **ФИО подписанта** — под полем показан предпросмотр склонения.
   Поле **«Действующий на основании»** подставляется само: у директора — Устава,
   у остальных подписантов — доверенности, у ИП не указывается вовсе (фраза
   «действующего на основании…» из договора исчезает). Выбор можно поменять
   вручную, тогда автоподстановка больше не вмешивается. Если выбрана
   доверенность, появляются поля **номера и даты доверенности** — они попадут
   в договор: «…действующего на основании доверенности № 3 от 03.12.2025 г.».
5. Отметьте галочку **«Я проверил данные — они верны»**. Ниже откроется
   **предпросмотр** готового договора — видно, как он будет сформирован.
6. Если всё устраивает — нажмите **«Скачать .docx»** или **«Скачать PDF»**
   в окне предпросмотра.
   Если есть замечания — **снимите галочку** (или просто исправьте любое поле),
   предпросмотр скроется и можно продолжить редактирование.

## Как обновить шаблоны договоров

Если типовой договор изменился, отредактируйте соответствующий файл в папке
`templates/` в Word. **Не трогайте текст в фигурных скобках** — это метки
подстановки (`{client_name_full}`, `{client_inn_kpp}` и т.д.). Полный список меток:

| Метка | Что подставляется |
|---|---|
| `{doc_number}` | номер договора |
| `{doc_date}` | дата договора в виде «30» июля 2026 г. |
| `{client_name_full}` | полное наименование клиента вместе с ОПФ |
| `{client_name_short}` | сокращённое наименование (ООО «…») |
| `{client_named}` | «именуемое» / «именуемый» / «именуемая» — по роду клиента |
| `{client_basis}` | оборот «, действующего на основании Устава» или «…доверенности № 3 от 03.12.2025 г.» целиком, с ведущей запятой; для ИП пусто — фраза исчезает из договора |
| `{client_acting}` | только «действующего» / «действующей» — по полу подписанта |
| `{client_signatory_role}` | должность подписанта в род. падеже |
| `{client_signatory_gen}` | ФИО подписанта в родительном падеже |
| `{client_signatory_sign}` | подпись: Фамилия И.О. |
| `{client_legal_address}` | юридический адрес |
| `{client_postal_address}` | почтовый адрес |
| `{client_phone}` | телефон |
| `{client_email}` | e-mail |
| `{client_inn_kpp}` | ИНН/КПП |
| `{client_ogrn}` | ОГРН |
| `{client_account}` | расчётный счёт |
| `{client_corr_account}` | корреспондентский счёт |
| `{client_bik}` | БИК |
| `{client_full_requisites}` | единый блок реквизитов (только шаблон ТО) |

Чтобы добавить метку в новом месте — просто впишите её в текст договора в Word.

> **Важно:** не вписывайте перед `{client_name_full}` и `{client_name_short}`
> организационно-правовую форму («ООО «…»»). Она уже входит в подставляемое
> значение, иначе получится «ООО «ООО «Ромашка»»». По той же причине пишите
> `{client_named}` и `{client_acting}` вместо «именуемое» и «действующего» —
> иначе договор с ИП или с женщиной-подписантом будет с ошибками в роде.

## Про .doc и PDF

- **Карточки в старом формате .doc** браузер напрямую не читает. Пересохраните
  такую карточку как **.docx** (в Word: Файл → Сохранить как → docx) или заполните
  поля вручную.
- **PDF на выходе** формируется через окно печати браузера. Для максимально точного
  соответствия оригиналу рекомендуется скачивать **.docx** и сохранять в PDF из Word
  (Файл → Сохранить как → PDF).

## Офлайн-режим (без интернета)

Ничего настраивать не нужно: все библиотеки лежат в папке `lib/` рядом с
приложением, внешние сайты не нужны. Достаточно веб-сервера, отдающего папку.

В `lib/` лежат: `pizzip` 3.1.7 (чтение и сборка .docx), `docxtemplater` 3.50.0
(подстановка меток), `FileSaver` 2.0.5 (сохранение файла), `pdf.js` 3.11.174
(чтение карточек в PDF). Чтобы обновить любую из них, замените файл на новую
версию той же библиотеки и проверьте, что предпросмотр по-прежнему строится.
